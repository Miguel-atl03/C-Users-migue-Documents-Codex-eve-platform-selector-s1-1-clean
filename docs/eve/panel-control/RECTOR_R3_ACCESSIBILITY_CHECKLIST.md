# R3 — Accessibility checklist (corrección)

- [x] refreshing: `role="status"` + texto “Actualizando información…”
- [x] fatal: `role="alert"` + foco en resumen + Reintentar por teclado
- [x] loading: `aria-busy="true"`
- [x] stale/partial: aviso textual (no solo color)
- [x] soft-refresh accesible (`panel-soft-refresh` / stale retry)
- [x] drawer Atención: Escape + retorno de foco (conservado)
- [x] iconos decorativos: no sustituyen el texto de estado
